一、项目概述
--------------------------------------------------------------------------------
AudioDownloader 是一个基于 Python 的自动化工具，专门用于从 B站（哔哩哔哩）
收藏夹中批量下载视频、提取音频、压缩音频文件，并自动管理元数据。
项目采用模块化架构设计，具有完善的日志系统和并发处理能力。

  作者：YKDX
  版本：1.0.0
  开发语言：Python
  操作系统：Windows
  创建日期：2026/2/15
  最后修改：2026/7/29

四、核心流程分析
--------------------------------------------------------------------------------

【主流程】

  1. 初始化应用 (initialize_app)
     ├─ 依赖检查 (you-get等工具)
     └─ 创建目录结构 (log/data/audio_orig/audio_comp)

  2. 配置管理 (manage_config_files)
     ├─ 更新配置文件
     └─ 读取配置参数

  3. 日志系统初始化
     ├─ 终端日志 (setup_terminal_log)
     └─ 文件日志 (setup_file_log)

  4. 数据爬取 (crawl_favorites)
     └─ 调用B站API获取收藏夹数据

  5. 数据过滤 (filter_and_classify_data)
     ├─ 读取已下载文件标签
     ├─ 过滤已下载内容
     └─ 分类媒体数据

  6. 统计生成 (generate_statistics)
     └─ 生成视频信息统计文件

  7. 并发下载 (concurrent_download)
     └─ 线程池调用you-get下载视频

  8. 并发压缩 (concurrent_compression)
     └─ 线程池调用Selenium自动化压缩

  9. 名称提取 (extract_and_rename_files)
     ├─ 提取关键词
     ├─ 重命名文件
     └─ 处理重复名称（创建文件夹）

【并发机制】

项目使用 ThreadPoolExecutor 实现并发：

  - 下载并发：task_executor/downloader/main.py
    通过 max_download_workers 控制线程数

  - 压缩并发：task_executor/compressor/main.py
    通过 max_compress_workers 控制线程数

【重试机制】

项目在多处实现了指数退避重试：

  # 网络爬取重试 (network_client/crawler/main.py)
  for attempt in range(network_retry):
      waiting_time = min(2 ** attempt, 5)  # 指数退避，最大5秒
      time.sleep(waiting_time)

  # 视频下载重试 (network_client/downloader/download_bilibili_video.py)
  for attempt in range(network_retry):
      waiting_time = min(2 ** attempt, 5)  # 指数退避，最大5秒
      time.sleep(waiting_time)


五、关键特性
--------------------------------------------------------------------------------

【1. 音频压缩方案】

项目采用浏览器自动化方式实现音频压缩：

  1. 使用 msedgedriver 自动安装Edge驱动
  2. 通过 Selenium 控制Edge浏览器
  3. 随机User-Agent防检测
  4. 自动化上传文件 -> 提交压缩 -> 获取下载链接

  注意：此方案依赖第三方压缩网站，存在稳定性风险

【2. 智能去重】

data_processor/filter/main.py 通过读取已下载文件的音频标签，避免重复下载。

【3. 名称冲突处理】

extract_and_rename_files 采用以下策略：
  - 提取文件名关键词
  - 遇到重名时创建子文件夹
  - 保留原始文件名

【4. 元数据编辑】

支持 MP3 和 FLAC 格式：
  - 使用 mutagen 库
  - 支持标签编辑
  - 支持封面图片嵌入
